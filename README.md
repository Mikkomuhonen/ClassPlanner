# ClassPlanner
Class Planner - Week Schedule Management

## Prerequisites

### Required Software

1. **Node.js (v18 or later)**
   - Download from: https://nodejs.org/
   - Choose the LTS (Long Term Support) version
   - This includes npm (Node Package Manager)

2. **Verify Installation**
   After installing Node.js, verify in PowerShell:
   ```powershell
   node --version
   npm --version
   ```

## Setup Instructions

### 1. Install OpenSpec
After Node.js is installed, run:
```powershell
npm install -g @fission-ai/openspec@latest
```

### 2. Verify OpenSpec Installation
```powershell
openspec --version
```

## Quick Start

1. Install Node.js from https://nodejs.org/
2. Open PowerShell and navigate to this directory
3. Run: `npm install -g @fission-ai/openspec@latest`
4. Start using the planner
